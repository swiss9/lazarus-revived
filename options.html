Save passwords
Off by default. While off, password fields and anything that looks like a card, one-time code or recovery phrase is ignored. Turning this on stores passwords in the vault.

Security

reading…

Set PIN

Encrypt every draft with AES-256-GCM. There is no recovery if you lose the PIN.

Unseal vault

Enter the current PIN to unlock the vault for this session.

Change PIN

Replace the current PIN. Drafts stay encrypted and are re-wrapped with the new one.

Remove PIN

Remove encryption and store the vault as plain text. Anyone using this browser profile can then read every draft.

Erase everything
Permanently delete every draft, the index and the PIN. This cannot be undone.

Backup

Export & import
Export writes every draft to a plain JSON file. That file is not encrypted — store it somewhere safe. Import merges drafts that do not already exist.

About

Lazarus records form fields as you type and keeps the history of every draft, so a crash, a stray navigation or a forgotten tab never costs you your words. Everything is stored locally with browser.storage.local; nothing is ever sent anywhere.

By default password fields, card numbers, one-time codes and wallet recovery phrases are deliberately ignored.

Lazarus is free: no ads, no tracking, no paid tier. Donations are the only thing that pays for the time it takes to keep it working as browsers change. If it has saved you from retyping something long, you can drop a little in the tip jar below — it is never required.

Thanks to the original Lazarus Form Recovery addon and its authors: it rescued a lot of lost text before it was abandoned, and this project only exists because of it.
